# 月の見え方ラボ

小学6年「月の形と太陽」の観察・モデル実験をつなぐ学習用Webアプリ。

- 月齢と時刻を独立に操作し、宇宙からの図・地球から見える月・南向きの空を比較。
- 夕方・朝・位置から形を考える3つの課題。名前とヒントの非表示にも対応。
- ライブラリ・外部フォント・解析・個人情報入力なし。静的ファイルだけで動作。
- 月齢は平均29.5日の周期による目安。空は北緯35度・赤緯0度の簡略モデルで、実際の日時の予報ではない。
- 月の満ち欠けは球面の照明から描画。日食・月食は対象外。
- 内容の確認：国立天文台 https://www.nao.ac.jp/faq/a0201.html

教科書本文・図版・テスト問題の転載なし。位置番号1〜8は独自の番号。

# 月の見え方ラボ

小学6年「月の形と太陽」の観察・モデル実験をつなぐ学習用Webアプリ。

公開：https://johnnymaeta.github.io/tsuki-to-taiyo/
授業用短縮URL：https://bit.ly/tsuki-taiyo

## 学習用モデル

月齢と時刻を独立に操作し、宇宙からの図・地球から見える月・南向きの空を比較。
夕方・朝・位置から形を考える3つの課題。名前とヒントの非表示にも対応。
平均29.5日周期、北緯35度・赤緯0度の簡略モデルで、実際の日時の予報ではありません。

## 実際の空・月齢カレンダー

- 都市または緯度・経度、現地日付・時刻、IANAタイムゾーンを指定（1900〜2100年）。
- 実際の新月からの経過時間による月齢、地心輝面比、観測地点からの月の方位角・高度・傾き。
- 現地日付の月の出・月の入り・日の出・日の入り。夏時間と出入りのない日にも対応。
- 現地正午の月齢カレンダー。日付を押して観察日を切り替え、新月・上弦・満月・下弦の日時を表示。
- 高度は標準大気差込み。標高0m、平らな地平線。天候・山・建物・月食の暗さは含みません。
- カレンダーの小図は北を上にした満ち欠けの模式図。大きな月と空の図は天頂を上にして傾きを表示。
- 夏時間で存在しない現地時刻は入力エラー、重複する時刻は先の時刻を採用し画面に明記。

## 実行・検証

静的ファイルを配信するだけで動作。ビルド不要。計算は端末内で行い、入力内容を送信・保存しません。
外部フォント・解析・外部CDNへの依存なし。

```sh
python3 -m http.server 8765
node --test tests/astronomy.test.js
```

天文計算は Astronomy Engine 2.1.19（MIT）：https://github.com/cosinekitty/astronomy
`vendor/astronomy.browser.min.js` は npm 配布物から同梱し、冒頭の著作権・ライセンス表示を保持しています。
テストは国立天文台2026年10月の朔弦望、月齢のリセット、時差・夏時間・うるう年、南北半球の位置、独立した投影式による月の傾き、出入りの現地日付を検証します。

照合：https://eco.mtk.nao.ac.jp/koyomi/yoko/2026/rekiyou263.html
学習内容：https://www.nao.ac.jp/faq/a0201.html

教科書本文・図版・テスト問題の転載なし。位置番号1〜8は独自の番号。日食・月食は再現しません。
